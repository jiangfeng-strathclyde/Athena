# INTEGRITY · 科研诚信三重审计（旗舰模块）

> 口号：**让论文里的每个数字都可追溯。**
> 在生成式 AI 让"产纸"变便宜的时代，可信度是比聪明度更稀缺的能力。本分身把可信度做成硬流程。

## 三重审计 + 一道取证扫描

| 层 | 技能 | 查什么 |
|---|---|---|
| 引用审计 | `citation-audit` | 每条书目真实存在、作者/年份/venue 正确、且**引用上下文确实被所引论文支持**（抓 hallucinated authors、错年、编造 venue、错上下文引用） |
| 双盲交叉核对 | `citation-crosscheck` | 一个 agent 从 .bib 逐字抽取、另一个盲态从网络重取记录、第三个做机械字段级 delta（抓丢作者/作者顺序错/DOI 错） |
| 数字-结论审计 | `paper-claim-audit` | 稿中每个数字、比较、范围声明 vs 原始结果文件；用**零上下文**的跨模型审稿人防确认偏误 |
| 实验诚实度审计 | `experiment-audit` | 假 ground truth、分数归一化作弊、幻影结果、范围不足 |
| 投稿前取证 | `integrity-forensics` | span 级证据台账 → 审计器提议发现 → 纯规则报告器逐条列出，转成类型化策略门 |

## 生成-校验分离（日常硬流程）

- 表/图/宏由**生成脚本**产出，正文零手抄；
- **独立校验脚本**从原始 fold 级 CSV 用不同实现重算同一批量，容差外即 FAIL 构建；
- 校验还做**文字许可检查**：例如写"indistinguishable"要求 |Δ| 落在运行间变异带内且 p>0.05；
  写"all Pareto points are ours"要求 Pareto 计数相等；
- 检查点/结果做 SHA256 + 有限性扫描，manifest 入档；损坏件 fail-closed 排除、原始行保留加注。

## 为什么这套东西让人眼前一亮

1. 它把"AI 助手会 hallucinate"从风险变成**可审计对象**：每个结论挂证据 span。
2. 它对抗的不只是模型，还有**人自己的确认偏误**（零上下文审稿人、双盲抽取）。
3. 它可裁剪：最小可用集 = `citation-audit` + `paper-claim-audit` + `experiment-audit` 三件套，
   任何写作流程都能即插即用。

## 使用提示

- 审计类技能默认调用跨模型审稿后端；后端缺失时按技能声明跳过或报错，**不得伪造审计结论**。
- 审计输出是证据清单而非判决书：最终取舍由作者做（分身不代决）。
