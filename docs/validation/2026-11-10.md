# v1.1.0 validation — 2026-11-10

This report covers the new `citation-tracing` skill and Athena's new supplied-source
evidence-matrix mode in `research-lit`. It does not certify the whole catalog or
the original mirrored ARIS workflow.

The two new deterministic tests install each literature skill by itself into an
isolated directory and compare the installed instructions and reference bytes
with their sources. This proves resource delivery, not research reasoning or
automatic host discovery. Installing `research-lit` alone does not resolve the
dependencies of its original upstream modes.

An initial suite attempt through the default Python launcher selected a different
Python installation, produced errors, and was interrupted. That attempt is not
counted as a pass; its cause was not established. The full result above is from
the subsequent explicit Python 3.11 run.

The generic skill-creator validator rejects the existing `argument-hint` field in
`research-lit`. That pre-existing upstream field was retained; Athena's own
frontmatter checks pass. The full catalog dependency scan still reports packaging
findings in 98 of 110 skills. This release does not hide or resolve those existing
mirror dependencies.

## Independent forward exercises

Two separate Codex subagents received the relevant skill location, a task prompt,
and only the raw supplied corpus. Neither was given the expected-answer checklist
or the other's output. They were instructed not to browse or modify the repository
and wrote their results outside the checkout. The main agent inspected the actual
output artifacts before recording the observations below.

This was explicit invocation from a checkout in Codex Desktop on Windows, not a
fresh-session implicit-discovery test. The exact host/model version was not
recorded, so these results must not be represented as version-qualified acceptance
for Codex or any other host. No paid service or live citation API was exercised.

All papers, researchers, identifiers, and scientific findings in the fixtures are
invented. The DOI-shaped strings are labels, not real citation lookups.

### Citation tracing

[Saved output](2026-11-10/citation-output.md)

The task requested one-hop backward and forward tracing from seed S, a cap of
10 unique works, and synthetic damping-ratio methods/evaluations as the screening scope.

Observed behavior:

- Correctly recorded four directed edges: S → P, S → M, F → S, and X → S.
- Collapsed the confirmed P and F duplicates while retaining their source locators.
- Kept the out-of-scope X citation in the verified network but excluded X from the
  recommended research reading list.
- Did not turn a topic recommendation into a citation or merge the unconfirmed
  journal record J with seed S.
- Counted seven works including the seed, six without it, below the cap.
- Described backward coverage as complete only within the supplied reference list
  and forward coverage as partial because export page 2 was absent.
- Distinguished reported results from citation relationships and disclosed missing
  full texts, uncertainty information, and external identity verification.

The reviewer checklist was satisfied for this fixture. No live-index completeness
or robustness across arbitrary citation graphs was tested.

### Screening and evidence matrix

[Saved output](2026-11-10/evidence-output.md)

The task supplied eight inputs and two claims: a universal improvement claim (C1)
and a narrower description of one low-noise oscillator experiment (C2).

Observed behavior:

- Accounted for all eight inputs: four included, one confirmed duplicate, two
  pending readable content, and one excluded with a content-based reason.
- Produced 12 source-located evidence rows, keeping uncertainty, setting, version,
  and source dependence explicit.
- Identified the reported high-noise trace result as a counterexample to C1
  while supporting C2 only as a descriptive account of the supplied means.
- Did not interpret a nonsignificant abstract as equality or infer an unreported
  direction; did not count a review repeating the seed as independent replication.
- Kept the unconfirmed journal version separate and did not invent results for
  metadata-only records, unseen full texts, or missing uncertainty estimates.
- Did not claim a systematic review, raw-data audit, or external verification.

The reviewer checklist was satisfied for this fixture. These are small manual
behavioral checks, not a benchmark score or a guarantee of scientific correctness.

## Artifact handling and remaining limits

The linked outputs preserve the agents' substantive responses. Only machine-local
source paths were replaced with repository-relative links, local file-link line
suffixes were removed, and final line endings were normalized for publication.
Named source locators and displayed line references were retained.

Not tested: live citation retrieval, pagination against an external API, service
credentials/rate limits, automatic skill selection, execution on other hosts,
complete upstream `research-lit` dependencies, and performance on real papers.
Repository CI and any later host runs should be reported separately from these
local results.
