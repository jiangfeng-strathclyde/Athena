A real data-checking example

You > Put “+3.2 ΔmIoU” in the abstract. It sounds stronger.

Assistant > I recomputed the claim from the raw results:
        +3.2 appears only for seed 0. Seeds 1 and 2 give +0.7 and −0.4.
        Mean ± sample std = +1.17 ± 1.84. Reporting only +3.2 would be cherry-picking.

        Options:
        A. Report +1.17 ± 1.84 — no new compute, weaker claim.
        B. Run two more seeds — about 6 GPU-hours, stronger evidence.
        C. Keep +3.2 but label it “single seed” — short edit, limited confidence.

        You choose; I will make the corresponding change.

How to use it

The process is always the same: you state a goal → it assembles a skill chain → it presents a plan and its costs → you choose → it executes and reports every change.

Three pillars

Triple integrity audit

References, numerical claims, and experimental integrity are checked separately so that every important claim remains traceable.

Load-before-task protocol

Any capable model can inherit the same constraints by reading three files. The protocol is portable, modular, and auditable.

Transparency log

Blocked upstream skills, licensing limits, corrections, and known errors are recorded publicly rather than hidden.

Project boundaries

  • The public repository does not include private memory, secrets, unpublished data, or identifying information.
  • When evidence or model access is missing, the assistant must say so explicitly instead of inventing a conclusion.
  • Only skills with clear licensing information are mirrored; blocked items are documented in the transparency log.
  • Original project content is MIT licensed; upstream attribution is preserved in skills/NOTICE.md.
  • The system is extensible: adding a skill means adding one SKILL.md file. See CONTRIBUTING.md.

Athena is an open-source research clone kit: 109 mirrored SKILL.md skills, a goal-first routing protocol (you state the goal, it assembles the skill chain), and an integrity triple-audit pipeline that makes every number in a paper traceable.
