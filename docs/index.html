What

A local research control plane

It plans work, records progress, registers artifacts, and enforces an export gate.

Input

A question, paper, or dataset

Begin with a goal and local source files or references you want the project to track.

Output

A versioned Research Release

Export a source-linked package that another person can inspect and verify offline.

A visible path from question to release.

Athena separates control from execution. The CLI states the next action; your local agent, script, or research process performs it; Athena records the result.

Plan

Register the goal and sources, then create a deterministic sequence of steps.

Resume locally

Receive the next-action contract without a hidden model call or external write.

Checkpoint

Mark the step complete and register the artifact produced by the work.

Export and verify

After every step is complete, package the release and verify its hashes offline.

Integrity is a workflow, not a badge.

A valid package can still contain a weak method or incorrect interpretation. Athena preserves the material needed for scrutiny; researchers and reviewers remain responsible for scientific judgment.

Sources remain visible

Record where an input or piece of evidence came from and what could not be accessed.

Artifacts remain accountable

Export checks registered files against their recorded bytes and SHA-256 hashes.

Boundaries remain explicit

Package verification confirms integrity. It does not certify that a scientific claim is true.

Extend the workflow

110 research skills, behind one clear product.

The wider catalog remains available to compatible hosts, with 107 selected by the full installer by default. Routing can select a bounded subset for a goal; across all three core stages, the canonical order is citation-tracing → research-integrity-pipeline → explorable-paper → Research Release. Athena does not automatically execute the selected skills, and each additional skill can have its own tools and dependencies.
