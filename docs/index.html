任务前加载协议

任何模型读三个文件即继承约束；零平台依赖、可裁剪、可审计。

透明度日志

被扫描器拦截的技能不绕过并公开记录；“不开源什么”写成清单；自己的误判也记。

边界

  • 公开版不含记忆包、密钥、未发表数据与可识别身份的信息；
  • 跨模型后端缺失时审计降级并明示，不伪造结论；
  • 镜像只收有许可声明的技能；21 个只列名不镜像，原因见透明度日志；
  • 自有内容 MIT；上游署名保留在 skills/NOTICE.md。

English (short)

Thats-me is an open-source research clone kit: 96 mirrored SKILL.md skills, a goal-first routing protocol (you state the goal, it assembles the skill chain), and an integrity triple-audit pipeline that makes every number in a paper traceable.

Load it in any model by reading three files; it audits before it edits, refuses cherry-picked numbers, and always hands you costed options instead of silently changing your manuscript. MIT licensed; upstream attributions preserved in skills/NOTICE.md.
