# Athena synthetic damped-oscillator case study

Athena includes a self-contained interactive page built from a deliberately
synthetic textbook model.

- Live artifact: <https://jiangfeng-strathclyde.github.io/Athena/examples/damped-oscillator.html>
- Repository copy: `docs/examples/damped-oscillator.html`

The page explores the unforced linear model
`m x'' + c x' + k x = 0`. Its controls change damping ratio, natural
frequency, initial displacement, and initial velocity. Every curve is computed
from the displayed closed-form equations in the browser.

This is a teaching fixture, not a paper reproduction. It contains no private
research data, unpublished results, literature-derived benchmark, or empirical
claim. Reuse its provenance labels, limitation disclosures, responsive layout,
and deterministic control-to-figure pattern—not its visual styling verbatim.
