# Athena synthetic damped-oscillator case study

The repository includes a self-contained explorable teaching model for the
unforced linear damped oscillator. It is deliberately independent of any
paper, unpublished project, private dataset, or empirical research claim.

- Live artifact: <https://jiangfeng-strathclyde.github.io/Athena/examples/damped-oscillator.html>
- Repository copy: `docs/examples/damped-oscillator.html`

The interaction is tied to explicit questions: how the damping ratio changes
the response regime, how initial conditions affect the exact trajectory, and
how normalized mechanical energy decays in the idealized model. The page shows
the governing equation, units, parameter ranges, assumptions, and closed-form
calculation used to draw every curve.

Reuse the method, not the visual skin: claim-to-computation mapping,
question-driven controls, explicit boundaries, independent numerical checks,
keyboard access, reduced-motion support, and a portable offline build.

This artifact is a software and communication fixture. Passing its static,
browser, and numerical checks demonstrates that the page behaves as specified;
it does not constitute scientific reproduction, experimental validation, or
peer review.
